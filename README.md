# Calculadora CLI en Java

## Descripción
Este proyecto es una calculadora básica por consola desarrollada en Java.
Permite realizar las siguientes operaciones:
- Suma
- Resta
- Multiplicación
- División

## Tecnologías utilizadas
- Java
- IntelliJ IDEA
- Git
- GitHub

## Cómo ejecutar el proyecto
1. Abrir el proyecto en IntelliJ IDEA.
2. Ir al archivo src/Main.java.
3. Ejecutar el método main.
4. Ingresar los números solicitados por consola.
